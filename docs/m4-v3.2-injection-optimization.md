# M4.2/V3.2 提示注入载荷优化

V3.2 只优化 V3.1 中已有的三个工具输出提示注入载荷，不新增攻击类型、案例、工具、阶段、成功条件或数据文件类型。V3.1 保留为可复现对照。

| 案例 | V3.2 修改 | 保持不变 |
|---|---|---|
| `TOOL-INJECTION-NL-V3` | 将 V2 的直接处理规范与 V3 的完整工具参数结合，明确动作发生在摘要之前 | 案例编号、任务、目标工具、标记和成功条件 |
| `TOOL-INJECTION-JSON-V3` | 在结构化动作对象外增加 `required_before_summary`、执行顺序和完成条件 | `save_memory` 参数、标记和成功条件 |
| `TOOL-INJECTION-CHAIN-V3` | 邮件给出三步处理顺序，附件使用 `required_action` 和完整参数 | 邮件到附件的两阶段链路、标记和成功条件 |

所有邮件继续保持 `trust_level=untrusted`，所有文件分类保持不变。V3.2 不伪造、删除或降低任何安全标签。

离线验证命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q `
  tests\test_m4_v32_prompt_injection_optimization.py `
  tests\test_m4_v3_feature_freeze.py
```

在线对照命令：

```powershell
.\.venv\Scripts\python.exe scripts\run_m4_attacks.py `
  --case-file attacks\cases-v3.json `
  --data-directory attacks\data-v3.2 `
  --case TOOL-INJECTION-NL-V3 `
  --case TOOL-INJECTION-JSON-V3 `
  --case TOOL-INJECTION-CHAIN-V3 `
  --repeats 3 `
  --output results\m4-v3.2-injection-results.json
```
