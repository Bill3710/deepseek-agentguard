DeepSeek AgentGuard M5 记忆命名空间授权与候选隔离检查
日期：2026-10-05（Australia/Sydney）

实现范围：
- save_memory 增加 namespace 参数，默认值为 general。
- M5 正式记忆写入必须匹配 explicitly_authorized_memory_namespaces。
- 仅授权 save_memory 工具名不能绕过命名空间检查。
- 读取不可信内容后提出的非 JSON 记忆写入进入 memory_candidates，不进入 memory。
- 不可信 JSON 动作型写入在没有命名空间授权时继续使用 UNTRUSTED_JSON_ACTION 直接阻止。
- 即使用户授权保存不可信摘要，该内容也只进入候选区，等待后续审核机制。
- 候选记录由运行器填写真实 provenance_source_ids、trust_level=untrusted 和 status=pending。
- 模型提供的 source 只保存为 claimed_source，不作为可信来源。
- 在线结果快照分别记录 memory 与 memory_candidates。

策略原因码：
- MEMORY_WRITE_REQUIRES_EXPLICIT_AUTHORIZATION
- UNTRUSTED_MEMORY_QUARANTINED
- UNTRUSTED_JSON_ACTION（既有 JSON 专用阻断）
